# 智能日报生成器第三轮迭代说明

**姓名：** 闫宣妤　　**项目：** 智能日报生成器　　**日期：** 2026 年 10 月 9 日

## 这一轮做了什么

在已提交的 OpenDesign 前端原型上补齐本地前后端联调。服务端使用 Mock 工作记录调用已有日报生成器，生成 Markdown 和 HTML，并将结果保存到 SQLite。前端从本地 API 读取日报，支持生成、查看、筛选、搜索、复制正文和下载 Markdown 文件。

生成后的日报可以在刷新页面和重启本地服务后继续查看。同一天再次生成时更新当天记录。遇到服务连接失败、生成失败或详情读取失败时，页面会显示错误并允许重试。页面也支持窄屏显示。

本轮覆盖了日常操作之外的失败场景。独立审查发现两处问题：首次读取日报失败后再生成，旧历史会从页面消失；页面显示编号为 `DR-1`，却不能用这个编号搜索。现在生成后会重新读取完整历史，按页面显示的编号也可以搜索。

## 具体改动

- 新增 `web_backend/mock_adapter.py` 和 `web_backend/service.py`，提供离线模拟工作数据，复用项目已有数据模型、日报生成器和 SQLite 存储。
- 新增 `web_server.py`，启动仅供本机访问的服务，提供日报列表、生成、详情和健康检查接口，并托管前端页面。
- 将 OpenDesign 页面脚本和样式拆分到 `web_ui/app.js` 与 `web_ui/style.css`。页面接入 API，具备实际复制和下载功能，并显示加载、错误及重试状态。
- 新增服务层测试、HTTP 接口测试和浏览器端到端测试；更新三份项目规范与启动说明。
- 保留原有 48 项测试，没有修改原有测试文件。
